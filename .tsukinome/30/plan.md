# Plan — Issue #30: Add formatDuration helper for human-readable run time display

> Generated by Tsukinome. The technical blueprint for the work, approved before any code.

## Summary

Add a small self-contained utility module `src/format-duration.ts` exporting `formatDuration(ms: number): string` that maps a millisecond count to a compact human-readable string per the scale rules, with a colocated unit test file. Update the cost summary rendering (in `src/pipeline/cost.ts`) to display durations via `formatDuration` rather than raw milliseconds.

## Approach

Implement a pure function with guard clauses: return "0ms" for non-finite (NaN/Infinity/-Infinity) or values <= 0 (covers negative and -0). For 0 < ms < 1000 round to whole ms and suffix "ms". For 1000 <= ms < 60000 floor to whole seconds and suffix "s". For 60000 <= ms < 3600000 compute floor(minutes) and floor(remaining seconds) as "Xm Ys". For ms >= 3600000 compute floor(hours) and floor(remaining minutes) as "Xh Ym", dropping seconds. Use Number.isFinite for the finite check and integer arithmetic with Math.floor for component truncation and Math.round for sub-second rounding — no leading zeros, no locale formatting. The module is dependency-free ESM matching the repo's `type: module` / TypeScript conventions. In the cost summary code path, replace the raw-ms interpolation with a call to formatDuration. Keep changes minimal and localized; do not alter how durations are measured or stored.

## Affected Files

- `test/format-duration.test.ts` **(add)** — Unit tests covering all acceptance criteria and edge cases (vitest, matching existing test layout).
- `src/pipeline/cost.ts` **(modify)** — Render run duration in the cost summary using formatDuration instead of raw milliseconds (R10/AC9).

## Contracts

- export function formatDuration(ms: number): string; // returns compact human-readable duration: "0ms" for 0/negative/non-finite; "<n>ms" for sub-second (rounded); "<n>s" for <1min (floored); "<m>m <s>s" for <1hr; "<h>h <m>m" for >=1hr
